手写 softmax（数值稳定版）

题目/考点

大模型岗几乎必考的开场题。面试官会问：「写一个 softmax，注意数值稳定性」；追问链通常是：为什么减 max？→ 梯度怎么推？→ 减 max 会不会改变梯度？→ temperature 是什么？

思路：为什么这么写

为什么减 max：softmax(z)i = ez_i / Σez_j，分子分母同乘 e−m（m = 行内最大值）得 softmax(z)i = ez_i−m / Σez_j−m——数学上是恒等变换。数值上：float32 最大约 3.4×1038，e89 就溢出（float64 也在 e710 溢出），而训练中 logits 常到 ±50，直接 exp 必炸。减 max 后最大项为 e0=1，其余落在 (0,1]，和 ≥1，输出永不溢出。这其实就是 log-sum-exp 技巧的指数部分。

图：softmax 数据流——减 max 只是整体平移，输出分布不变；红色虚线框内三步合起来就是 softmax。

⓪ 保底解法（卡住时先写这个）

策略：紧张时先写「最直白版」——直接 exp 再归一化，不带减 max。它能跑通正常数值的自测用例，先把分数拿到；减 max 那行留到面试官追问「数值稳定」时再补，正好顺着话头展示你其实懂。
import numpy as np

def softmax(x):
    # 保底直白版：先写这个，能跑通正常数值的用例
    e = np.exp(x)                          # 注意：x 很大时这行会溢出（float32 在 e^89 就炸）
    return e / np.sum(e, axis=-1, keepdims=True)
    # 面试官追问「数值稳定」时补一行：x = x - np.max(x, axis=-1, keepdims=True)
    # 话术：减 max 是分子分母同乘 e^(-m) 的恒等变换，输出与梯度都不变，只是防溢出

写保底版的正确姿势：先说一句「我先写能跑的版本，数值稳定性待会儿补」——不会显得你不知道减 max，反而显得有条理。自测用例用正常数值（如 [1, 2, 3]），别拿 [1000, 1000, 1000] 去测这个版本。

① 力扣格式 · Python（numpy 手写版）

import numpy as np

def softmax(x):
    # x: (..., D)，沿最后一维做 softmax
    x = x - np.max(x, axis=-1, keepdims=True)   # 数值稳定：防 exp 上溢（关键一行）
    e = np.exp(x)                               # 最大项 = e^0 = 1，其余在 (0, 1]
    return e / np.sum(e, axis=-1, keepdims=True)

复杂度 / 面试追问

复杂度：每个向量 O(D)，batch 共 O(nD)；空间 O(nD)。

  • 梯度推导（dCE/dz = softmax(z) − y，务必会说）：记 p = softmax(z)，L = −Σk yk log pk（y 为 one-hot）。关键一步是 softmax 的 Jacobian：∂pk/∂zi = pk(δki − pi)，其中 δki 是 Kronecker delta（i=k 时为 pk−pk²，i≠k 时为 −pkpi，用商的求导法则一步得到）。链式法则代入：∂L/∂zi = Σk (−yk/pk)·pk(δki − pi) = −yi + pi·Σkyk = pi − yi。直觉：真实类梯度 py−1 为负（把 logits 往上推），其他类 pk 为正（往下压），推力与当前错误程度成正比——这正是 softmax+CE 比 MSE 好训的根源。
  • 减 max 会不会改变梯度？不会。softmax 对 z 的整体平移不变（分子分母同乘 e−m），输出不变则梯度不变；减 max 只是换了个数值安全的坐标系。
  • temperature：softmax(z/τ)。τ→0 逼近 argmax（分布变硬），τ→∞ 趋于均匀；知识蒸馏里用大 τ 软化教师输出，给学生更丰富的监督信号。
  • 下溢问题：减 max 只防上溢。全负大数时 ez 下溢为 0 是安全的（0 不破坏归一化）；真正危险的是 log(0)——所以 cross-entropy 要用 log-sum-exp 形式，而不是先 softmax 再取 log（见专题第 3 题）。

手写 self-attention（numpy 完整版 + mask）

题目/考点

面试官会问：「用 numpy 手写 self-attention」「QKV 是什么、shape 是多少」。追问链：为什么除以 sqrt(d_k)？mask 怎么加？多头怎么拆？复杂度是多少？

思路：为什么这么写

三个投影 Q = XWq、K = XWk、V = XWv（W 可训练）。scores = QKT 是「查询 i 与键 j 的相关性」，softmax 沿 K 维度（每行）归一化成注意力权重，再对 V 加权求和——本质是按相似度检索 + 按权重聚合。

为什么除以 sqrt(d_k)：假设 q、k 各分量独立、均值 0 方差 1，则内积 q·k = Σ qtkt 是 d_k 个独立项之和，方差为 d_k（方差可加性），量级约 sqrt(d_k)。d_k 大时 logits 巨大 → softmax 输出逼近 one-hot（饱和）→ 梯度接近 0 → 训练不动。除以 sqrt(d_k) 把 logits 方差拉回 1，softmax 落在梯度健康的区间。这是 Vaswani et al. 2017 原文给出的动机，和 softmax 减 max 是同一类「数值健康」问题。

图：self-attention 数据流——X 经三个线性变换（紫色小框，可训练权重）投影出 Q/K/V；QKᵀ 打分 → ÷√d_k（logits 方差从 d_k 拉回 1）→ softmax 逐行归一 → 加权求和 V。蓝色=矩阵乘，红色=softmax。

① 力扣格式 · Python（numpy 手写版）

import numpy as np

def softmax(x):                                  # 复用第 1 题的稳定版
    x = x - np.max(x, axis=-1, keepdims=True)
    e = np.exp(x)
    return e / np.sum(e, axis=-1, keepdims=True)

def self_attention(X, Wq, Wk, Wv):
    # X: (n, d_model)；Wq/Wk: (d_model, d_k)；Wv: (d_model, d_v)
    Q = X @ Wq                                   # (n, d_k)
    K = X @ Wk                                   # (n, d_k)
    V = X @ Wv                                   # (n, d_v)
    scores = Q @ K.T / np.sqrt(Q.shape[-1])      # (n, n)；除以 sqrt(d_k) 控制方差
    attn = softmax(scores)                       # 沿 K 维度（每行）归一化
    return attn @ V                              # (n, d_v) 按注意力加权求和

def self_attention_causal(X, Wq, Wk, Wv):
    Q, K, V = X @ Wq, X @ Wk, X @ Wv
    n = Q.shape[0]
    scores = Q @ K.T / np.sqrt(Q.shape[-1])
    causal = np.triu(np.ones((n, n), dtype=bool), k=1)  # 上三角=True：位置 i 屏蔽 j > i 的「未来」
    scores = np.where(causal, -np.inf, scores)          # 屏蔽位填 -inf，softmax 后权重严格为 0
    attn = softmax(scores)                              # 对角线上自己看自己不屏蔽
    return attn @ V

本题面试以 Python 为主。要点在公式与方差论证，不在语言；若要求 C++，把三个矩阵乘 + 行归一化写成循环即可。

复杂度 / 面试追问

复杂度：时间 O(n²d)（QKT 是 n² 次内积，每次 d_k 次乘法），空间 O(n²)（注意力矩阵）。n = 序列长度。

  • mask 怎么加（两种等价写法）：① 布尔 mask：scores = np.where(mask, -np.inf, scores)（True 的位置屏蔽）；② 加法 mask：scores = scores + mask_add（屏蔽位 −inf 或 −1e9，其余 0）。为什么 −inf 安全：softmax 内先减 max，exp(−inf)=0，权重严格为 0。但注意整行全屏蔽会 NaN（0/0），实践中对角线（自己看自己）总是不屏蔽的。
  • padding mask：变长序列的 padding 位置在 K 维度屏蔽（每行对应列填 −inf），与 causal mask 直接叠加。
  • 多头：d_model 切成 h 份各自算 attention，concat 后过 Wo——「不同子空间关注不同的关系」。
  • 为什么 softmax 后要加权求和而不是取 argmax？argmax 不可导（hard attention 无法训练）；softmax 让所有位置都有梯度，是 soft attention。
  • 主动展示的加分点：FlashAttention 把显存从 O(n²) 降到 O(n)（分块 + 在线 softmax，避免物化整个注意力矩阵）；推理时 KV cache 让 K/V 只算一次；能否不用 softmax——linear attention 用 kernel 分解交换计算顺序，复杂度降到 O(nd²)，但建模能力有取舍。

手写 cross-entropy + softmax 梯度合并推导

题目/考点

面试官会问：「手写 cross-entropy，注意数值稳定」「推导 softmax 和 CE 合并后的梯度」。高频追问：为什么不先 softmax 再 log？label smoothing 对梯度有什么影响？

思路：为什么这么写

CE = −Σk yk log pk，衡量两个分布的距离；对 one-hot 标签退化为 −log py（真实类别的负对数概率）。数值稳定写法用恒等式 log py = zy − logΣez_j（log-sum-exp）：先减 max 再求 log，全程无 exp 溢出、无 log(0)。

为什么不能先 softmax 再 log：① softmax 输出可能下溢为精确的 0，log(0) = −inf；② 白多算一遍 exp；③ 合并梯度 p−y 是解析上最干净的形式。PyTorch 的 nn.CrossEntropyLoss 内部就是 log_softmax + NLL，所以务必传 logits 而不是概率。

图：cross-entropy 示意——真实标签是 one-hot，求和只剩真实类一项：CE = −log p(y)；p(y) 越小损失越大（惩罚「错误且自信」）。

⓪ 保底解法（卡住时先写这个）

策略：先写「公式直译版」-log(softmax(x)[y])——和数学定义一一对应，绝不出错，先落笔；面试官一问数值问题，立刻过渡到 log-sum-exp 稳定版：把 log 与 softmax 合并成 z[y] - logΣexp(z)，正好引出「log-sum-exp 的导数就是 softmax」这句全场最漂亮的话。
import numpy as np

def cross_entropy_naive(logits, y):
    # 保底公式版：−log p_y，直译定义，先写这个（正常数值下能跑）
    p = np.exp(logits) / np.sum(np.exp(logits), axis=-1, keepdims=True)  # softmax
    return float(np.mean(-np.log(p[np.arange(len(p)), y])))              # -log(softmax(x)[y])

# 过渡到稳定版：log p_y = z_y − logΣexp(z_j)，先减 max 防溢出、无 log(0)
def cross_entropy(logits, y):
    z = logits - np.max(logits, axis=-1, keepdims=True)
    log_sum_exp = np.log(np.sum(np.exp(z), axis=-1))
    return float(np.mean(log_sum_exp - z[np.arange(len(z)), y]))

过渡话术：「公式版有两个问题——softmax 可能下溢成精确 0 导致 log(0)，以及先 exp 再 log 白绕一圈；所以实际写成 zy − logΣez，先减 max，PyTorch 的 CrossEntropyLoss 内部就是 log_softmax + NLL，所以要传 logits 而不是概率。」

① 力扣格式 · Python（numpy 手写版）

import numpy as np

def softmax(x):
    x = x - np.max(x, axis=-1, keepdims=True)
    e = np.exp(x)
    return e / np.sum(e, axis=-1, keepdims=True)

def cross_entropy(logits, y):
    # logits: (n, C) 未归一化分数（务必传 logits，不要先 softmax）
    # y: (n,) 整数标签 或 (n, C) one-hot
    z = logits - np.max(logits, axis=-1, keepdims=True)   # 数值稳定（同 softmax）
    log_sum_exp = np.log(np.sum(np.exp(z), axis=-1))      # (n,) 即 log(Σ exp(z_j))
    if np.asarray(y).ndim == 1:
        z_y = z[np.arange(len(z)), y]                     # 每行取真实类别的 z
        return float(np.mean(log_sum_exp - z_y))          # CE = logΣexp - z_y
    else:
        return float(np.mean(log_sum_exp - np.sum(y * z, axis=-1)))  # one-hot 版

① 力扣格式 · C++（可选：仅核心数学部分）

本题面试以 Python 为主。核心是「logΣexp − zy」这一行公式，语言无关。

复杂度 / 面试追问

复杂度：O(nC) 时间（每样本一次 exp 求和），空间 O(nC)。

梯度合并推导（面试推荐用短路径，从稳定形式出发）：

  1. 稳定形式：L = −Σi yi log pi，其中 log pi = zi − log Σj ez_j。
  2. 先求 log-sum-exp 的梯度：∂ log Σj ez_j / ∂zt = ez_t / Σez_j = pt——「log-sum-exp 的导数就是 softmax」，这是本题最漂亮的一句话。
  3. 于是 ∂log pi/∂zt = δit − pt，代入 ∂L/∂zt = −Σi yi(δit − pt) = −yt + pt·Σiyi = pt − yt。
  4. 与「softmax Jacobian」路径（第 1 题）完全等价但少一半步骤——两条都会，面试用这条短的。
  • label smoothing：标签换成 y' = (1−ε)y + ε/C，梯度变为 p − y' = p − (1−ε)y − ε/C。效果：真实类梯度被削弱一点、其他类被轻轻上推，防止模型对训练标签过自信（正则化）。
  • 为什么 CE 配 softmax 比 MSE 好？① 合并梯度 p−y 没有饱和因子——MSE 配 sigmoid 输出层时梯度含 σ'(z)，σ 饱和时梯度消失；② 最小化 CE 等价于最大似然估计（MLE）；③ CE 对「错误且自信」的惩罚大，收敛快。
  • 二分类特例（会讲即可）：CE = −[y log σ(z) + (1−y) log(1−σ(z))]，合并梯度 dL/dz = σ(z) − y，与多分类同构。

手写 KMeans（一轮迭代 + 完整循环）

题目/考点

面试官会问：「手写一轮 KMeans 迭代」或完整循环。追问链：K 怎么选？初始化有什么讲究（KMeans++）？为什么收敛？什么数据上会失效？KMeans 和 KNN 的区别？

思路：为什么这么写

一轮迭代 = 两步：① 分配（每个点找最近中心，argmin）；② 更新（每簇取均值作为新中心）。为什么均值是最优：固定分配后，对 SSE = Σ||x − c||² 求导，∂SSE/∂c = Σ2(c − x) = 0 解得 c = 簇内均值——「最小二乘的解析解」。

收敛性直觉：两步都是「SSE 单调不增」的坐标下降，而样本的划分方案总数有限，所以必终止；但可能停在局部最优——这正是 KMeans++ 和多随机重启存在的原因。numpy 广播技巧：X[:, None, :] - centers[None, :, :] 一次算出全部 (n×k) 距离。

图：KMeans 一轮迭代——分配 + 更新两步都使 SSE 单调不增，划分方案有限 ⇒ 必收敛（但可能局部最优，需 KMeans++/多重启）。

⓪ 保底解法（卡住时先写这个）

策略：完整循环（for + 收敛判断 + 空簇兜底）一时写不完整，就先只写「随机选 k 个点 + 一轮迭代」——分配与更新两个核心步骤都在里面，短到不会错；然后口述完整版怎么补：「外面套 for 循环，中心不再变化就 break，空簇重新随机初始化」。一轮迭代本身就是常考的出题形式。
import numpy as np

def kmeans_step(X, centers):
    # 保底短版：一轮迭代 = ① 分配 + ② 更新，先把这两步写对
    dist = np.linalg.norm(X[:, None, :] - centers[None, :, :], axis=2)  # (n, k) 广播
    labels = dist.argmin(axis=1)                     # ① 分配：每个点归入最近中心
    return np.array([X[labels == k].mean(axis=0)
                     for k in range(len(centers))])  # ② 更新：簇内均值

# 完整循环口述版：centers = X[随机选 k 个样本]；for _ in range(iters):
#   新中心 = kmeans_step(...)；空簇 → 重新随机初始化该中心；
#   与旧中心 np.allclose → break（收敛）；否则继续。
#   收敛理由：两步都使 SSE 单调不增 + 划分方案有限 → 必终止（可能局部最优）

短版即正解的一半——你缺的只是外面那层循环，而循环纯靠嘴说也够。唯一易错点是广播那行 dist，写之前在脑子里过一遍 (n,1,d) − (1,k,d) → (n,k,d)；mean 那行别忘了 axis=0（沿样本维取均值）。

① 力扣格式 · Python（numpy 手写版）

import numpy as np

def kmeans_step(X, centers):
    # X: (n, d)；centers: (k, d)
    dist = np.linalg.norm(X[:, None, :] - centers[None, :, :], axis=2)  # (n, k) 广播求距离
    labels = dist.argmin(axis=1)                      # 分配：每个点归入最近的中心
    new_centers = np.array([X[labels == k].mean(axis=0)
                            for k in range(len(centers))])              # 更新：簇内均值
    return labels, new_centers

def kmeans(X, k, iters=100, seed=0):
    rng = np.random.default_rng(seed)
    centers = X[rng.choice(len(X), k, replace=False)].copy()   # 随机选 k 个样本点作初值
    for _ in range(iters):
        labels, new_centers = kmeans_step(X, centers)
        for c in range(k):                             # 空簇兜底：重新随机初始化
            if not np.any(labels == c):
                new_centers[c] = X[rng.integers(len(X))]
        if np.allclose(new_centers, centers):          # 中心不再移动 → 收敛
            break
        centers = new_centers
    return labels, centers

复杂度 / 面试追问

复杂度：每轮 O(nkd)（n 样本、k 簇、d 维），t 轮 O(t·n·k·d)。

  • K 怎么选：① elbow 法（SSE-K 曲线找拐点）；② silhouette coefficient s = (b−a)/max(a,b)，a 是簇内平均距离、b 是到最近邻簇的平均距离，越接近 1 越好；③ 生产环境由下游业务指标定。面试话术：「先讲清方法，再说实际中用业务指标定」。
  • 初始化问题与 KMeans++：随机初始化可能两个中心落在同一簇，撞上坏局部最优。KMeans++：第一个中心随机选，之后每个新中心按「到已有最近中心距离的平方 D(x)²」加权采样——远点更可能被选中，期望意义下 O(log k) 近似比。
  • 为什么必收敛：分配与更新两步都使 SSE 单调不增 + 划分方案有限 → 一定终止；但只保证局部最优，所以实践里跑多次取 SSE 最小的一次。
  • 空簇：某簇没有样本时 mean 会是 NaN——重新随机初始化该中心（代码里已兜底）。
  • 失效场景：簇非球形（同心圆、月牙形）、大小悬殊、密度不均——KMeans 隐含假设「欧氏距离 + 各向同性」。替代：GMM（软分配 + 协方差，KMeans 是其在各向同性协方差下的硬分配特例）、DBSCAN（密度）。
  • KMeans vs KNN：KMeans 无监督、训练期反复迭代；KNN 有监督、推理期算距离——面试官爱考这个区分。

手写 IoU + NMS（纯 numpy）+ Soft-NMS

题目/考点

多模态岗几乎必考，纯文本岗偶考：「手写 IoU」→「手写 NMS」。追问链：NMS 有什么问题？Soft-NMS 怎么改？为什么现在的检测器有不用 NMS 的？

思路：为什么这么写

IoU = 交集 / 并集。交集四步：左上交 max、右下交 min、宽高与 0 取 max（不相交时截成 0）、面积相乘；并集 = A + B − 交集（容斥原理）。NMS = 贪心：按分数降序，最高分的框必保留，压掉所有与它 IoU 超过阈值的框，对剩余重复。核心假设：「同一个物体只保留一个框，重叠多的框是冗余」——记住这个假设，后面所有改进都是冲它去的。

图一：IoU = 交集 / 并集，并集 = A + B − 交集（容斥）；代码里交集的四个 max/min 就为算红色这块。

图二：NMS 贪心流程——按分数降序，最高分必保留；其余框与保留框 IoU ≥ 阈值（0.5）即被抑制。核心假设「重叠 = 冗余」在密集场景会误杀，故有 Soft-NMS。

⓪ 保底解法（卡住时先写这个）

策略：放弃 numpy 广播炫技，写最直白的双重循环版——IoU 用四个 max/min 一行行来，NMS 用 while + 列表推导逐个压，不预计算 iou_matrix。代码更长但每个变量都看得见，几乎不可能写错；向量化优化是加分项不是必选项，写完补一句「内层循环可以换成矩阵运算加速」即可。
import numpy as np

def iou(a, b):
    # 保底版：交叠左上取 max、右下取 min，负宽高截 0
    x1, y1 = max(a[0], b[0]), max(a[1], b[1])
    x2, y2 = min(a[2], b[2]), min(a[3], b[3])
    inter = max(0, x2 - x1) * max(0, y2 - y1)
    union = (a[2]-a[0])*(a[3]-a[1]) + (b[2]-b[0])*(b[3]-b[1]) - inter  # 容斥
    return inter / (union + 1e-9)      # +1e-9 防两个退化框除零

def nms(boxes, scores, thresh=0.5):
    # 保底版：分数降序，最高分保留，压掉与它 IoU 超阈值的框，对剩余重复
    order = sorted(range(len(boxes)), key=lambda i: -scores[i])
    keep = []
    while order:
        i = order[0]
        keep.append(i)                              # 当前最高分必保留
        order = [j for j in order[1:] if iou(boxes[i], boxes[j]) < thresh]
    return keep

写这一版时嘴里同步讲：交叠区域 = max 左上 + min 右下；并集 = 面积和 − 交集（容斥）；NMS 是贪心——「同一个物体只保留一个框，重叠多的框是冗余」。双重循环版跑完自测再考虑换 iou_matrix 广播版，时间不够就直接口述「矩阵化可以一次算完两两 IoU」。

import numpy as np

def iou(box1, box2):
    # box: (x1, y1, x2, y2) 左上 / 右下
    x1 = max(box1[0], box2[0]); y1 = max(box1[1], box2[1])   # 交叠左上 = 取 max
    x2 = min(box1[2], box2[2]); y2 = min(box1[3], box2[3])   # 交叠右下 = 取 min
    inter = max(0, x2 - x1) * max(0, y2 - y1)                # 不相交时截成 0
    a1 = (box1[2] - box1[0]) * (box1[3] - box1[1])
    a2 = (box2[2] - box2[0]) * (box2[3] - box2[1])
    return inter / (a1 + a2 - inter + 1e-9)                  # +1e-9 防两个退化框除零

def iou_matrix(boxes1, boxes2):
    # (n, 4) 与 (m, 4) -> (n, m)，一次算出所有两两 IoU
    lt = np.maximum(boxes1[:, None, :2], boxes2[None, :, :2])   # 交叠左上
    rb = np.minimum(boxes1[:, None, 2:], boxes2[None, :, 2:])   # 交叠右下
    wh = np.clip(rb - lt, 0, None)                              # 宽高，负值截为 0
    inter = wh[:, :, 0] * wh[:, :, 1]
    area1 = (boxes1[:, 2] - boxes1[:, 0]) * (boxes1[:, 3] - boxes1[:, 1])
    area2 = (boxes2[:, 2] - boxes2[:, 0]) * (boxes2[:, 3] - boxes2[:, 1])
    union = area1[:, None] + area2[None, :] - inter             # 容斥
    return inter / (union + 1e-9)

def nms(boxes, scores, thresh=0.5):
    order = np.argsort(scores)[::-1]             # 分数从高到低
    keep = []
    while len(order):
        i = order[0]                             # 当前最高分框必保留
        keep.append(i)
        order = order[1:]
        if len(order) == 0:
            break
        ious = iou_matrix(boxes[i:i+1], boxes[order])[0]   # 当前框 vs 剩余框
        order = order[ious < thresh]             # 只留重叠小的（iou_matrix 广播加速）
    return keep

def soft_nms(boxes, scores, thresh=0.5, sigma=0.5, min_score=0.001):
    # Soft-NMS：不删除，而是衰减分数（高斯版；线性版 scores[j] *= 1 - ov）
    scores = scores.copy()                       # 原地修改分数，先拷贝
    order = np.argsort(scores)[::-1].tolist()
    keep = []
    while order:
        i = order.pop(0)                         # 当前最高分框
        keep.append(i)
        alive = []
        for j in order:
            ov = iou(boxes[i], boxes[j])
            if ov >= thresh:                     # 重叠大：衰减分数而非删除
                scores[j] *= np.exp(-(ov * ov) / sigma)   # 高斯惩罚，重叠越多衰减越狠
            if scores[j] >= min_score:           # 衰减到阈值以下才移除
                alive.append(j)
        order = alive
    return keep

复杂度 / 面试追问

复杂度：两两 IoU 最坏 O(n²)，NMS 贪心循环 O(n²)。

  • NMS 的缺陷：① 贪心 + 硬阈值——IoU 0.51 和 0.49 结果天壤之别；② 密集场景（人群、货架）真实目标相互重叠被误杀；③ 分数低的框可能定位更准但被压掉；④ 分数不更新——被压框的置信度信息被浪费。
  • Soft-NMS 改进（Bodla et al. 2017）：对重叠框不删除而是衰减分数 sj ← sj·f(IoU)，线性版 f = 1−IoU，高斯版 f = exp(−IoU²/σ)；分数低于 min_score 才移除 → 密集目标有机会存活。代价：多一个 σ（或线性版无参）超参。
  • 其他改进（会讲名字即可）：DIoU-NMS 加中心点距离惩罚；Weighted NMS 按分数加权平均框坐标；NMS-free 路线——DETR 用匈牙利匹配做一对一二分图匹配，彻底绕开 NMS（这也是「为什么新检测器不用 NMS」的标准答案）。
  • 工程细节：NMS 前通常先按类别分组（类内 NMS）+ 分数阈值过滤低分框；「为什么 +1e-9」——防止两个零面积退化框除零。

3 层 MLP：前向 + 手动推导反向（dW/db 公式）

题目/考点

面试官会问：「写出 3 层 MLP 的前向，手动推导每个 dW/db」。追问链：ReLU 的反向是什么？为什么框架要缓存前向激活？sigmoid 为什么梯度消失？

思路：为什么这么写（三条规则 + 维度检查）

先立符号：层输出 al = f(zl)，zl = al−1 Wl + bl；损失 L 对 zl 的梯度记 δl（上游梯度）。反向传播只有三条规则：

  • 线性层反向：dW = aT·δ（外积求和），db = δ 按 batch 求和（损失取平均则 /n），上游继续流 δprev = δ·WT（乘转置！）。为什么 dW = aTδ：W[c,d] 影响所有样本的 z[:,d]，∂L/∂W[c,d] = Σs a[s,c]·δ[s,d] = (aTδ)[c,d]。
  • ReLU 反向：⊙ 1[z > 0]——「开关」：输入为正梯度原样通过，否则归零。
  • 输出层特例：softmax + CE 合并后 δout = p − y（第 1/3 题的结论直接套）。

维度检查（写不出公式时的救命稻草）：W 是 (d_in, d_out)，a 是 (n, d_in)，δ 是 (n, d_out) → aTδ 是 (d_in, d_out)，与 W 同形 ✓；δWT 是 (n, d_in)，与 a 同形 ✓。推导乱了就靠维度把矩阵乘顺序拼回来。

⓪ 保底解法（卡住时先写这个）

策略：反向推导卡壳时，先把前向写出来（不会卡），然后按「输出层 → 线性层 → ReLU」从后往前逐层口述，每层只背三句：线性层 dW = xᵀ@d_out、过 ReLU 乘掩码、输出层 CE+softmax 梯度是 p−y。三行口诀写在注释块里交卷，配合维度检查兜底——这题要的是「知道每层怎么流」，不是完整可跑的反向代码。
# ===== 保底口诀三行（写在注释里交卷也够用）=====
# 线性层:  dW = xᵀ @ d_out,  db = sum(d_out),  上游继续流 = d_out @ Wᵀ（乘转置！）
# ReLU:    d_in = d_out * (z > 0)              # 开关：正放行、负归零
# 输出层:  d_logits = p − y                     # softmax + CE 合并梯度（专题 1/3 结论）

def mlp_forward(X, W1, b1, W2, b2, W3, b3):
    # 前向先写出来，反向全靠它对照：z = X@W + b，a = relu(z)，连三层
    z1 = X @ W1 + b1;  a1 = np.maximum(0, z1)
    z2 = a1 @ W2 + b2; a2 = np.maximum(0, z2)
    z3 = a2 @ W3 + b3                          # logits（接 softmax + CE）
    return z3, (X, z1, a1, z2, a2, z3)

# 逐层口述：δ3 = p − y → dW3 = a2ᵀ@δ3, db3 = Σδ3
#          → δ2 = (δ3 @ W3ᵀ) * (z2 > 0) → dW2 = a1ᵀ@δ2, db2 = Σδ2
#          → δ1 = (δ2 @ W2ᵀ) * (z1 > 0) → dW1 = Xᵀ@δ1,  db1 = Σδ1

口述时每过一层线性层说「dW = 输入转置乘上游、db = 上游求和、上游换成乘 WT」，每过一层 ReLU 说「乘上 (z>0) 的掩码」。真忘了某步的矩阵顺序，就用维度检查现场拼：dW 形状必须等于 W，左乘项取输入的转置就对了；δWT 的形状必须等于上一层激活。

import numpy as np

def relu(x):
    return np.maximum(0, x)

def mlp_forward(X, W1, b1, W2, b2, W3, b3):
    # X: (n, d0)；W1:(d0,d1) W2:(d1,d2) W3:(d2,C)，C 为分类数；输出 logits
    z1 = X @ W1 + b1            # (n, d1) 预激活
    a1 = relu(z1)               # 激活
    z2 = a1 @ W2 + b2           # (n, d2)
    a2 = relu(z2)
    z3 = a2 @ W3 + b3           # (n, C) 输出 logits（接 softmax + CE）
    cache = (X, z1, a1, z2, a2, z3)   # 反向传播需要缓存这些中间量
    return z3, cache

复杂度 / 面试追问

复杂度：前向 O(n·(d0·d1 + d1·d2 + d2·C))，反向同阶（矩阵乘转置）。

记忆口诀：「线性乘转置，激活当开关；softmax 合 CE，梯度 p 减 y。dW = 输入转置乘上游，db = 上游求和。」——把 δ 想象成水流：过线性层方向换成乘 WT，过 ReLU 被开关过滤，到输出层由 p−y 注入。
  • 为什么框架要缓存前向激活？反向需要 a 和 z（dW 用 a、ReLU 开关用 z）。不缓存就要重算——gradient checkpointing 就是「时间换显存」的重算策略，训练大模型常用。
  • sigmoid 为什么梯度消失？σ'(z) = σ(1−σ) ≤ 1/4，多层链式连乘指数衰减；ReLU 在激活区导数为 1，不衰减 → 缓解梯度消失 + 稀疏激活；但 z ≤ 0 恒零导数 → 死神经元，LeakyReLU（0.01x）兜底。
  • 为什么「softmax+CE 合起来是 p−y」让输出层特别好训？误差即梯度——预测错得越多梯度越大，且没有 σ' 饱和因子，训练早期不会「卡住」。

力扣 56 合并区间 × 3 变体（小红书重点）

题目/考点

小红书风格代表题：先出标准版，再现场改条件——「左闭右开」「间隔 ≤ k 也可合并」「只输出合并后个数」。考的不是算法多难，而是识别差异的速度和「排序 + 贪心」模板的熟练度。注意小红书用牛客 OJ（ACM 模式），要自己读 stdin（包装代码见下）。

思路：为什么这么写

核心洞察：按起点排序后，重叠判断退化为「当前起点 vs 已合并区间的终点」的单条件比较——不需要和每个已有区间比。为什么排序就够：若当前区间与 res 最后一个不重叠，它与前面所有区间都不重叠（前面区间的终点都被 res 末尾的终点覆盖），贪心正确。

三个变体的差异全部落在 if 那一行（这是本专题最该背的一页）：标准闭区间重叠当且仅当 s ≤ prev_end → 新区间条件 s > prev_end；左闭右开端点相触不算重叠 → s >= prev_end；间隔 k 内可合并（间隔 = s − prev_end ≤ k 时合并）→ s > prev_end + k。合并动作不变：res[-1][1] = max(res[-1][1], e)（起点已排序，起点必被覆盖）。

⓪ 保底解法（卡住时先写这个）

策略：变体条件记混了就先写标准闭区间版——排序 + 单扫 + 比较 prev_end，90% 正确率的模板，先落笔；写完对照面试官的条件改边界那一个字符（> → >=、prev_end → prev_end + k）。模板不变、只有 if 那一行变，这本身就说明你吃透了「识别差异」。
# 保底标准版（闭区间，端点接触算重叠）——先写这个，再按条件改 if 一行
def merge(intervals):
    intervals.sort()                          # 按起点排序（起点相同按终点）
    res = []
    for s, e in intervals:
        if not res or s > res[-1][1]:         # 无重叠：开新段
            res.append([s, e])
        else:
            res[-1][1] = max(res[-1][1], e)   # 重叠：扩展终点
    return res

# 变体对照（只改 if 那一行）：
# 左闭右开  → s >= res[-1][1]        （端点相触不算重叠）
# 间隔 ≤ k  → s > res[-1][1] + k    （间隔 = s − prev_end，> k 才分家）
# 只问个数  → 不建 res，用单变量 cur_end 计数，空间 O(1)

    for s, e in intervals:
        if not res or s > res[-1][1]:       # 与上一个区间无重叠（s > prev_end）
            res.append([s, e])
        else:
            res[-1][1] = max(res[-1][1], e) # 有重叠：扩展终点
    return res

vector<vector<int>> merge(vector<vector<int>>& a) {
    sort(a.begin(), a.end());                 // 默认先按起点、再按终点排序
    vector<vector<int>> res;

概率题 3 道：贝叶斯 / 连续正面 / 蓄水池采样

题目/考点

小红书常考三道：① 贝叶斯患病率问题（患病率 1%、假阳 5%，求 P(患病|阳性)）；② 抛硬币连续 2 次正面的期望次数（E=6）；③ 蓄水池采样（n 个未知长度流中等概率取 k 个，写代码 + 证明）。考的是「概率直觉 + 能把直觉写成方程」，不考背诵。

思路：为什么这么写

① 贝叶斯——先澄清题干（这一步本身就是加分）：严格说贝叶斯题需要「灵敏度 P(+|患病)」，只给患病率和假阳率算不出答案。面试标准版本补全为：患病率 1%、灵敏度 99%、假阳 5%（若假设患病必检出即灵敏度 100%，答案 16.8%，几乎一样——关键在假阳基数）。计算过程：

P(+) = P(+|患病)P(患病) + P(+|健康)P(健康)        # 全概率公式拆分母
     = 0.99 × 0.01 + 0.05 × 0.99
     = 0.0099 + 0.0495 = 0.0594
P(患病|+) = P(+|患病)P(患病) / P(+)               # 贝叶斯公式
     = 0.0099 / 0.0594 = 1/6 ≈ 16.7%

直觉（必讲的一句）：假阳 5% 作用在 99% 的健康人身上，阳性人群里绝大部分是假阳——「基数大 × 小概率 > 基数小 × 大概率」，这是 base rate 效应，也是这道题要考的东西。速算版（优势比）：先验 odds = 0.01/0.99 ≈ 1/99，似然比 LR = 0.99/0.05 ≈ 20，后验 odds ≈ 20/99 ≈ 0.2 → P = 0.2/1.2 ≈ 16.7%。

图：贝叶斯树（千人化为 1 万人）——base rate 效应：假阳 5% 打在 99% 健康人身上，阳性总数 594 里真阳仅 99；高亮的两条路径都汇入「阳性」。

② 连续两次正面——状态方程法：E0 = 从零开始（当前连续正面数 0）的期望，E1 = 已有一个正面时的期望。先掷一次：反面（½）回状态 0，正面（½）进状态 1。为什么能用「E = 1 + 平均后续」：马尔可夫性——未来的期望只依赖当前连续正面数，于是可以列线性方程组：

E0 = 1 + ½E0 + ½E1        # 掷一次：T 回状态 0，H 进状态 1
E1 = 1 + ½E0 + ½·0        # 再掷：H 直接完成（后续 0），T 回状态 0
→ E1 = 1 + E0/2
→ E0 = 1 + E0/2 + (1 + E0/2)/2 = 3/2 + 3E0/4
→ E0 = 6 ✓

记忆：单次成功是几何分布 E = 1/p = 2；连续 k 次正面 E = 2k+1 − 2（k=2 → 6，k=3 → 14）。彩蛋：图案 HT（非自重叠）期望只有 4，比 HH 的 6 小——自重叠图案会「浪费」已积累的进度，状态法对任意图案通用。

③ 蓄水池采样——为什么是 k/(i+1)：数据流长度 n 未知或超大，内存只够 k 个，要求每个元素最终入选概率都是 k/n。核心：前 k 个直接入池；处理到第 i+1 个元素（0 基下标 i）时，以 k/(i+1) 概率替换池中随机一项。这个概率的设计目标是归纳不变量：处理完前 i+1 个元素后，池中每个元素入选概率恰为 k/(i+1)（证明见追问）。

⓪ 保底解法（卡住时先写这个）

策略：概率题没代码可写时，保底姿势是口述推导 + 写三个关键公式——展示「能把直觉写成方程」，即使忘了具体数字也比干瞪眼强。每题一个锚点：贝叶斯先写分母全概率公式、期望题先列状态方程、蓄水池口述归纳法。推导讲完再上代码（三题里只有蓄水池有代码）。

# ③ 蓄水池（口述保底）：归纳法三句话
#    归纳假设：处理完前 t 个，池内每元素入选概率 k/t
#    新元素：以 k/(t+1) 概率入选 ✓

import random

def reservoir_sampling(stream, k):
    # 单遍扫描、O(k) 内存；stream 长度未知也适用
    pool = []
    for i, item in enumerate(stream):        # i = 0 基下标，已见 i+1 个元素
        if i < k:                             # 前 k 个直接入池
            pool.append(item)
        else:
            j = random.randint(0, i)          # 以 k/(i+1) 的概率替换池中随机一项
            if j < k:                         # P(j < k) = k/(i+1) ✓
                pool[j] = item
    return pool

# 等概率自测：100 个元素取 10 个，重复 20000 次统计每个元素的出现频次
from collections import Counter
cnt = Counter()
for _ in range(20000):
    for x in reservoir_sampling(range(1, 101), 10):
        cnt[x] += 1
# 期望频次 = 20000 × 10 / 100 = 2000；实测每个元素都在 1900~2100 之间（均匀 ✓）
print(min(cnt.values()), max(cnt.values()))

复杂度 / 面试追问

复杂度：蓄水池 O(n) 时间、O(k) 空间；前两题 O(1)。

  • 蓄水池等概率证明（归纳法，必背）：归纳假设：处理完前 t 个元素后，每个元素入选概率 k/t（基础步：前 k 个时概率 1 = k/t ✓）。归纳步（t+1）：新元素以 k/(t+1) 入选 ✓；旧元素此前在池中（概率 k/t），若新元素不替换（概率 1 − k/(t+1)）或被替换但没替换到它（概率 k/(t+1) × (k−1)/k = (k−1)/(t+1)），则存活，总存活率 = 1 − k/(t+1) + (k−1)/(t+1) = t/(t+1)。于是旧元素终选概率 = (k/t) × t/(t+1) = k/(t+1) ✓。归纳到底即 k/n。
  • 加权蓄水池（元素有权重 wi，按 w 成比例入选）：A-Res 算法——给每个元素随机 key = u1/w（u ~ U(0,1)），维护 key 最大的 k 个。直觉：−ln(u)/w 服从 Exp(w)，是指数竞赛模型——权重越大的元素越容易「先到」，入选概率正比于 w。
  • 硬币题变体：连续 k 次 E = 2k+1 − 2；图案 HT vs HH（自重叠差异）；通用解法永远是列状态方程。
  • 贝叶斯题变体：「第二次检测还是阳性，概率多少」——把第一次后验 16.7% 当新先验再套一次贝叶斯（假设两次检测独立）。
